PX4 + ROS 2 Drone Control

A short talk, a guided simulation, and a real flight. Learn the basics of offboard drone control with PX4 and ROS 2.

1

Presentation

40 minutes

  • PX4 ecosystem and flight modes
  • ROS 2 nodes, topics, and timing
  • Coordinate frames
  • Structure of an outer-loop controller
2

Simulation

Hands-on

  • Read vehicle position and velocity
  • Generate a waypoint, square, or circle
  • Write a position controller that sends acceleration commands
  • Run it in Offboard mode
3

Real flight

Hands-on

  • Meet the hardware
  • Watch the switch to Offboard mode
  • Run a verified controller
  • Observe hover, waypoints, or a short trajectory

By the end, you will be able to

  • Describe the PX4 flight-control architecture
  • Identify common PX4 flight modes
  • Explain how ROS 2 communicates with PX4
  • Read vehicle state through ROS 2
  • Generate simple trajectory references
  • Implement a basic outer-loop controller
  • Test an offboard controller in SITL and on a real vehicle
